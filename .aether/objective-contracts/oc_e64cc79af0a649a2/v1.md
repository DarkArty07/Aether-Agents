# Objective Contract: Formalize, complete and dogfood the Aether laboratory (#252)

## Owner Intent

Christopher autoriza trabajo autónomo de largo horizonte mientras está ausente: convertir el laboratorio E2E experimental en una capacidad formal, ordenada y explicada del proyecto; terminar sus gates; usar Morfeo-lab aislado para probar `aether_observe`; corregir bugs mínimos; notificar hitos y blockers críticos por Telegram.

## Objective

Entregar un laboratorio Aether formal, mantenible, documentado y compatible con los comandos actuales; completar paralelismo aislado y la lane persistente; añadir una suite de autodiagnóstico donde Morfeo-lab use observación curada; ejecutar la calificación real y dejar bugs corregidos con evidencia.

## Decisions and Assumptions

Decisiones: implementación formal en `src/aether_agents/lab`; assets/docs descubribles en área `lab/`; `scripts/e2e` queda como wrapper compatible. Paralelismo máximo default 2, sólo escenarios independientes; E2E-15 y lanes sensibles a sesión son seriales. Morfeo-lab diagnostica pero nunca edita Aether. Suite nueva `observation` separada del rolling gate hasta calificarse. Supuesto delegado: usar proveedor/modelo ya provisionado, sin credenciales nuevas, con corrida live acotada y rerun sólo del fallo.

## In Scope

Formal package/API; top-level lab documentation and contracts; compatibility wrappers; scenario/fixture/evidence schemas; bounded parallel matrix; isolation checks; observation status/changes and diagnose/anomaly scenarios with seeded real traces; machine checks for actual tool calls, caps and forbidden raw fallback; native persistent-session probe/gate; prepare-only/full tests; bounded live observation run; GitHub issues/regressions/fixes/reruns; Telegram milestones.

## Out of Scope

Fuera: Morfeo-lab productivo o compartiendo board/home; autoedición de Aether por el evaluado; daemon/dashboard/notifier/evaluator LLM nuevos; logs/eventos crudos en contexto; elevar concurrency sin límite; incorporar observation al rolling 20 antes de estabilidad; push, publish, deploy, OIDC, credenciales, #242 cutover, cambios Hermes core, cuentas o gasto no acotado.

## Authority

Supervisor decide descomposición, interfaces compartidas e integración; debe fan-out antes de expansión de contexto y respetar #251. Implementers modifican worktrees, prueban y entregan commits. Morfeo integra/recupera sólo si pipeline se bloquea, ejecuta live lab, abre/cierra issues y notifica Telegram. Autorizado: trabajo local reversible, modelos ya provisionados para corrida acotada, procesos disposable. No autorizado: efectos remotos, credenciales, publicación, reinicio/cutover productivo salvo autorización ya existente explícita.

## Deliverables

Código formal del lab; wrappers compatibles; docs top-level/README/roadmap; schemas y suites; tests unitarios/integración/isolation/parallel; observation scenarios y fixtures; persistent lane con evidencia; reports JSON/JSONL; live run artifacts; issues y commits de bugs; informe final basado en Git, tests, board y outputs; mensajes Telegram de inicio, arquitectura integrada, primera corrida live y final/blocker.

## Acceptance Criteria

Acepta si: comandos históricos pasan; package lab importable; prepare-only full y observation verdes; `--parallel 2` ejecuta roots aislados sin compartir home/board/state/worktree; observation lanes prueban tool calls reales status/changes/diagnose, salida caps y cero terminal/file/raw fallback; evaluado no cambia Aether; E2E-15 usa evento/sesión Hermes nativo o bloquea con wall demostrado; corrida live acotada pasa o cada fallo tiene issue+test+fix+same-route rerun; suite afectada, Ruff y diff verdes; docs permiten operar sin conocimiento tribal.

## Testing Standard

TDD por tracer vertical: RED para compat wrapper, formal loader, isolation y bounded parallel; luego observation fixtures/tool-call acceptance; luego persistent lane. Tests deterministas sin modelo primero. Integración real con Hermes/PluginManager/SQLite/Git. Live: máximo dos Morfeo-lab concurrentes, una corrida por scenario y rerun sólo del fallo, usando modelo/provider existente; evidence debe probar llamadas reales. Test unitario/mock-only no acepta. Canary de infraestructura antes y después de cambios del harness.

## Stop Conditions

Bloquear sólo por credencial/cuenta/gasto fuera del autorizado, efecto remoto/protegido, corrupción/dirty work ajeno, Project/contract mismatch, o capacidad Hermes necesaria demostrablemente ausente. Bugs normales: issue, regresión, fix mínimo, rerun. Si Supervisor repite #251 (compresión o >10 min sin fan-out), Morfeo detiene y recupera proporcionalmente. No detener por warnings, flakes recuperables o gaps de observación no funcionales; registrarlos. Telegram para blocker crítico, no cada warning.
