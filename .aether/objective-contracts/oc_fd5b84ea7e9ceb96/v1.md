# Objective Contract: Fix #263, #266 and #267 with minimal verified changes

## Owner Intent

Use the real Aether pipeline to repair all three open operational bugs #263, #266 and #267 with the smallest reversible changes. Backport only the already-merged upstream #263 fix; do not update Hermes generally. Preserve every unrelated local patch and all user state.

## Objective

Deliver one integrated, independently reviewed candidate that: backports upstream commit aa9aaaa6cb31753c3b274db6825fbd0af5f27120 for #263 as a removable Hermes local patch; makes disposable Kanban probe isolation reusable and mandatory for #267; and retains safe bounded failed-test node IDs for #266 without weakening the 450-test gate or adding retries.

## Decisions and Assumptions

Decisions: split implementation into three independent units and one terminal integration. #263 must be an exact minimal backport, not a redesign. #266 is diagnostics-only because failed node IDs are unrecoverable; no behavioral guess. #267 is Aether-only and reuses the existing lab environment helper. Supervisor and Implementer approvals remain off per owner decision; hardline and Aether hooks remain active.

## In Scope

#263: port only the upstream identity changes in tools/terminal_tool.py and hermes_cli/gateway.py, add exact regressions, create portable patch plus HERMES_LOCAL_PATCHES entry. #266: retain bounded sanitized FAILED/ERROR node IDs in qualifier evidence and test privacy. #267: publish/reuse isolated_hermes_env, clear complete outer Kanban/session identity, set disposable roots, and prove the live control DB is unchanged. Integrate, run full gates, open protected PR, merge only if green.

## Out of Scope

No general Hermes update, dependency migration, release, deploy, tag, package publication, credentials, new approval policy, retry-based masking, test removal, 450-gate reduction, cgroup-specific design, cron guard weakening, SOUL change, or unrelated cleanup. Morfeo alone may activate the #263 runtime patch and restart the gateway after integration evidence is green.

## Authority

Owner authorizes local reversible code/config/tests/docs, public upstream inspection, branches/commits, protected PR/CI/merge, and the bounded post-merge #263 gateway reload. No release or publication is authorized. Genuine new protected effects or missing credentials return to Morfeo.

## Deliverables

Code and regressions for #263/#266/#267; portable #263 Hermes patch with backup hashes, exact upstream reference, tests, reload/removal gate and active status after Morfeo canary; public Aether isolation helper; safe failure-node evidence; updated issue comments; one protected PR; final board/artifact handoff identifying any remaining uncertainty.

Use RED→GREEN for every bug. Run focused tests per unit, affected combined tests, then full locked Aether suite and CI-equivalent static/build/public-boundary gates. #263 additionally requires exact active-runtime tests, patch apply/reconstruction, gateway reload and Konsole same-path canary. #267 uses native subprocess/SQLite with a read-only live control. #266 tests synthetic failure output privacy and must not simulate a behavioral pass.
