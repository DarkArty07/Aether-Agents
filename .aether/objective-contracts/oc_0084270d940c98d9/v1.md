## Objective

Produce reviewed source changes and regression evidence that restore four bounded invariants: (310) delegated-child ownership markers cannot persist in reusable terminal environment snapshots or reappear in the originating parent, while genuine child mutation denial remains; (354) a project-bound Objective Contract can be authored/prepared from a verified isolated Git worktree without mutating the Project primary checkout, and its execution board creates new worktrees from the contract's exact base commit; (341) work-memory freshness includes tracked and untracked source changes, reflection cache hits verify note integrity first, and malformed note records return stable MEMORY_CORRUPT; (345) semantic fingerprints include the concrete non-secret auxiliary provider/model/API transport identity and incomplete explicit finish reasons (including length) cannot be cached/applied as complete output.

## Decisions and Assumptions

DECISIONS. D310: treat the delegation marker and dispatcher-owned HERMES_KANBAN_* variables as transient per-command identity, exclude them from the persistent shell snapshot export, and retain the existing ContextVar/process propagation and fail-closed Kanban DB guard; do not clear os.environ globally or weaken child denial. D354: derive the authoring root from the exact native Hermes session workspace (read-only session binding), accept only the registered project's primary checkout or a linked worktree sharing its Git common directory and carrying the same verified .aether/project.toml project UUID; store/read contract bytes there. Keep native Hermes Project identity and board default_workdir anchored to the registered primary path, and persist a validated generic board worktree base ref equal to the prepared contract HEAD so Kanban worktree creation uses that ref instead of incidental primary HEAD. Do not add a second Project or ask the model for an arbitrary path/base. D341: use the existing tracked-plus-untracked dirty-source semantics from snapshots.py; validate all immutable note metadata and markdown hash before any consumer/cache hit; preserve namespace isolation and cache invalidation. D345: resolve a non-secret concrete auxiliary route using the existing Hermes auxiliary resolution surface where available, include provider/model/api_mode in the fingerprint, carry route metadata through the existing call, and refuse cache reuse or cache publication when the actual route is unresolved/mismatched; an explicit non-terminal finish_reason such as length is incomplete even when content parses. Missing legacy finish_reason remains compatible only where the runtime response supplies no reason at all. These decisions assume no provider/credential/config changes and no paid live-model call is needed for acceptance.
