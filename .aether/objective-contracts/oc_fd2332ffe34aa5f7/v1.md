# Objective Contract: Resolve execute_code helper contract and search_files JSON framing defects (#313, #353)

## Owner Intent

The owner authorizes autonomous implementation and routine closeout of Aether issues #313 and #353 after approving the investigated design. Resolve both defects in the maintained DarkArty07/aether-hermes fork through an isolated Aether pipeline and its provisioned board/Project. Keep the two causes and evidence independent. Recheck concurrent changes before integration. Do not reuse or mutate the separate flow for issues #267/#292/#294/#295/#301/#304 (Objective Contract oc_5c2dad1b37b20a80@v1), and keep Graphify outside this objective.

## Objective

Deliver a reviewed, verified, integrated patch in DarkArty07/aether-hermes that (1) teaches the actual explicit-import contract for execute_code helpers json_parse, shell_quote and retry, including accurate recovery guidance, and (2) guarantees search_files truncation output remains one parseable JSON document so execute_code receives a dictionary instead of JSONDecodeError. Reconcile Aether's issue/patch records and perform routine GitHub closeout without activating or reloading the installed runtime unless separately authorized.

## Decisions and Assumptions

DECIDED — #313 is a contract/schema defect, not an absent helper: helpers are exports of generated hermes_tools.py and user script.py must import them. Correct schema, CLI tip and NameError/ImportError guidance; do not inject names into globals or Python builtins. Follow the behavior integrated upstream at commit 65f033a1a20e847b7a150fe6168cd345385c7d07, using the older-layout test shape of upstream PR #83772 where appropriate. DECIDED — #353 is a producer framing defect: tools/file_tools.py::search_tool serializes JSON and appends a plain-text truncation hint. Store that guidance in result_dict['_hint'] before the single json.dumps. Do not make the UDS/file/TCP RPC parser tolerate arbitrary suffixes. Follow merged upstream PR #104472 / commit 7a6c3b41c33a61601132c6bbf737735bd4a07207, adapted to this fork rather than blindly cherry-picked. DECIDED — retain distinct issue attribution and regression evidence even if Supervisor chooses one implementation unit because tests/tools/test_code_execution.py is shared. ASSUMED — the inspected bases remain origin/main 8af2575ccc3233c43b44bf40a5629ebec26e21da and origin/aether-main c185ee3bb5b6d609241432fd123c16143f065987; refresh before work and integrate a newer compatible base if either advances. ASSUMED — the loaded Hermes 0.20.1 target files remain byte-identical to aether-main: tools/code_execution_tool.py SHA-256 928d7bc88696ee5ee2ca84977ad4909f357aac376fd9312457adf13fe0eab88b and tools/file_tools.py SHA-256 18b40343d3fd890692762e8a434fa7e2e96b953766108a797b4af2caef01dd19. A mismatch invalidates the reproduction baseline and requires reinspection before mutation. LOCALLY DELEGATED — private test helper names and equivalent reversible test-fixture structure may vary, but public result shape, hints, preservation gates and attribution may not.
