# Objective Contract: Add native Graphify semantic extraction through the existing Aether Router auxiliary configuration

## Owner Intent

The owner approves autonomous delivery of the complete proposed Graphify expansion as a reusable Aether capability for all bound projects, not only the Aether Agents repository. Preserve the two native tool names and expand project_knowledge from eight to fourteen actions by adding stats, god_nodes, list_prs, pr_impact, triage_prs and visualize (graph/tree variants); work_memory retains five actions. Enhance update with native LLM semantic extraction using the provisioned auxiliary-model connection selected by the owner; enhance query with BFS/DFS, depth and explicit relation-context controls, impact with relation selection, and path with optional undirected traversal. Agents maintain semantics alongside ordinary committed graph updates without a separate human request; no permanent watcher or per-message extraction. The selected deployment connection is Aether Router with the already configured auxiliary model, no additional monetary cap while existing capacity lasts, and no account/provider/credential expansion. GitHub tools are optional read-only features for projects with an authorized GitHub binding. The owner requests autonomous implementation, tests, independent review, routine GitHub integration and verified usable local delivery. This is an objective-specific exception to the stabilization feature freeze, not authority for unrelated expansion. Existing corpus exclusions and project/revision/role isolation remain. Do not add external corpus connectors, other export formats, graph unions, training, hooks, provider management, or publication/deployment unrelated to this local capability.

Deliver the approved Graphify expansion for every bound Aether project. Automatically maintain semantic code/document knowledge through the existing auxiliary model. No material owner questions remain; this is design self-review, not Supervisor's independent approval.
