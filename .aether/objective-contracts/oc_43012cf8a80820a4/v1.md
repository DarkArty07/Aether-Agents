# Objective Contract: Retirar el falso confinamiento de rutas de terminal para Implementer

## Owner Intent

El propietario aprueba retirar únicamente la heurística que intenta confinar los procesos de terminal de Implementer buscando rutas absolutas dentro del texto del comando.

La terminal debe quedar disponible para trabajo ordinario. Permanecen las comprobaciones concretas de credenciales, contratos, contexto de tarea, rama y worktree, historia e integración Git, Kanban y efectos externos enumerados. No se introduce un parser alternativo, una excepción para Python, Bubblewrap, Docker ni otro sandbox. La decisión responde al fallo reproducido en el que una ruta legítima del entorno virtual fue bloqueada mientras programas arbitrarios todavía podían calcular escrituras exteriores que nunca aparecían en el comando.

## Objective

Retirar el falso confinamiento de rutas en terminal y execute_code. Conservar las guardias precisas y demostrar el desbloqueo mediante el caso real de #233.

## Decisions and Assumptions

Decisión del propietario: retirar la heurística sin parser ni sandbox sustituto. Supuesto comprobado: Aether no promete aislamiento físico entre roles que comparten el mismo usuario local.

## In Scope

Eliminar sólo el bloque genérico de rutas; ajustar pruebas, R10, documentación y changelog; sincronizar los tres perfiles; revisar; repetir la llamada real de #233.

## Out of Scope

No crear Bubblewrap, Docker, parser ni broker; no cambiar Hermes; no corregir #228 o #235; no tocar HERMES_LOCAL_PATCHES.md ni continuar la cualificación tras el siguiente bug.

## Authority

Autorizados cambios locales reversibles, pruebas, commits, sincronización con backup y E2E. Prohibidos push, release, deploy, credenciales, gasto y reinicio del gateway.

## Deliverables

Hook canónico mínimo; regresiones; documentos reconciliados; copias runtime con paridad y rollback; revisión independiente; evidencia E2E; actualización de #233.

## Acceptance Criteria

El bloque desaparece sin reemplazo genérico; la llamada exacta de #233 pasa; controles retenidos siguen denegando; suite y lint pasan; tres perfiles coinciden; revisión y E2E son verdes.

## Testing Standard

TDD con la llamada estructurada exacta de t_6b7e338c. Ejecutar test_policy_hooks completo, Ruff, compilación y diff-check; probar controles negativos; E2E con Implementer real sin usar uv run.

## Stop Conditions

Detener ante conflicto de proyecto o contrato, debilitamiento de un control retenido, fallo de backup o paridad, efecto protegido no autorizado, o primer bug posterior; preservar evidencia y reportar.
