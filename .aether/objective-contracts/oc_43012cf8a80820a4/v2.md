# Objective Contract: Retirar el falso confinamiento de rutas de terminal para Implementer

## Owner Intent

El propietario aprueba retirar únicamente la heurística que intenta confinar los procesos de terminal de Implementer buscando rutas absolutas dentro del texto del comando.

La terminal debe quedar disponible para trabajo ordinario. Permanecen las comprobaciones concretas de credenciales, contratos, contexto de tarea, rama y worktree, historia e integración Git, Kanban y efectos externos enumerados. No se introduce un parser alternativo, una excepción para Python, Bubblewrap, Docker ni otro sandbox. La decisión responde al fallo reproducido en el que una ruta legítima del entorno virtual fue bloqueada mientras programas arbitrarios todavía podían calcular escrituras exteriores que nunca aparecían en el comando.

## Objective

Retirar el falso confinamiento de rutas en terminal y execute_code. Conservar las guardias precisas y demostrar el desbloqueo mediante el caso real de #233.

## Decisions and Assumptions

Rama de integración del objetivo: feat/002-contract-observation, pues contiene el commit base y aún no debe entrar en main. Morfeo actualiza R10; los workers no mutan ese contrato.

## In Scope

Eliminar el bloque genérico; ajustar código, pruebas, documentación operativa y changelog; sincronizar perfiles; revisar; repetir #233. R10 ya fue actualizado por Morfeo.

## Out of Scope

No integrar Observation en main. No tocar, stagear, guardar en stash, restaurar ni incluir HERMES_LOCAL_PATCHES.md. No crear parser, sandbox ni corregir #228 o #235.

## Authority

Se autoriza declarar temporalmente AETHER_INTEGRATION_BRANCH=feat/002-contract-observation sólo al hook de Supervisor y restaurar su configuración al terminar. Sin reinicio.

## Deliverables

Hook, pruebas, documentación, changelog, copias runtime y E2E; integración en la rama declarada; configuración temporal restaurada; diff previo preservado byte por byte.

## Acceptance Criteria

Además de v1: integración en feat/002-contract-observation; HERMES_LOCAL_PATCHES.md conserva sus hashes previos; R10 no aparece en commits de workers; configuración temporal se restaura.

## Testing Standard

Además de v1: capturar hashes del archivo y diff ajenos antes y después; stagear rutas explícitas; verificar rama de integración en el hook; no usar git add -A.

## Stop Conditions

Detener si cambia el archivo o diff ajeno, si un worker toca R10, si la rama declarada no llega al hook, si Git exige stash o restore, o en el primer bug posterior.
