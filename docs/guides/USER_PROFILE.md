# User profile and memory

Hermes owns the user-facing continuity relationship through its native user profile, memory, session search and skills.

Store durable preferences in the user-profile mechanism; store stable environment facts in memory; keep project-specific truth in this repository; turn only generalized, verified procedures into skills. Do not store secrets, one-session scratch state or speculative conclusions as durable memory.

Aether does not require an external semantic-memory service. Removing a retired memory system does not authorize deletion of unrelated Hermes user data.
