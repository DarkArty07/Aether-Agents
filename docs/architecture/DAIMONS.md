# Supported profiles

A profile is a bounded role contract. A file on disk does not grant runtime availability, authority or permission to dispatch a model.

| Profile | Contribution | Limits |
|---|---|---|
| Hefesto | implementation, refactoring, integration and debugging | does not redefine product scope or self-accept critical work |
| Daedalus | UX flows, interaction, accessibility and prototypes | does not silently turn prototypes into production architecture |
| Ictinus | backend, data, APIs, scalability and architecture review | consultant; does not implement or acquire release authority |

Hermes remains responsible for general research, proportional security analysis, documentation and continuity. Ariadna, Athena and Etalides were removed because current policy classified them as disabled or forbidden; no renamed equivalent may bypass that choice.

Every admitted specialist Task defines one deliverable, exact project identity, allowed effects, forbidden actions, acceptance evidence and output format. Multiple workers may share an archetype only when their Tasks are independently scoped and separately identified.
