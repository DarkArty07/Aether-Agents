# M1 operational entry contract

The named local 0.23 runtime is installable, reversible and observable. General model-backed production entry remains pending.

## Accepted foundation

- package `aether-mcp==0.23.0.dev0` in an isolated machine-local environment;
- exact v1alpha2 protocol and 15-tool surface;
- enabled Hermes registration with a fresh session identity per process;
- exact provider build/catalog binding;
- owner-only state and rollback paths;
- secret-safe status and typed errors;
- import/server construction without creating Run, Task or worker effects;
- disable and rollback operations that preserve prior live configuration.

## Production-entry acceptance

One explicitly authorized case must prove, on the current boundary:

1. exact project admission and manifest validation;
2. Run/Task creation without implicit dispatch;
3. one bounded model-backed Dispatch under frozen provider/model/budget authority;
4. real participant correlation and message;
5. artifact verification and semantic disposition;
6. close plus zero attempt-owned survivors;
7. no retired fallback or unreported external effect.

Installation status, tool discovery or fixture denials alone do not satisfy this contract.
