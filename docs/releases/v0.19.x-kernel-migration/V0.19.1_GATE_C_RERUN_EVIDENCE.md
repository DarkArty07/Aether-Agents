### Confirmed cause

The dispatch lease expired at:

```text
1785111874472617170 ns
```

The assistant turn was persisted at:

```text
1785111875251618900 ns
```

The worker completed approximately 0.78 seconds after the initial dispatch lease expired. `HarmoniaService._stop()` called `KernelDispatcher.cancel_with()`, whose `_authority_current()` rejected the expired fence. Harmonia therefore mapped the stop to `authority_mismatch` before attempting ACP cleanup.

The runtime lacks a coherent path that renews authority while work remains active or ingests a naturally completed ACP session into a durable terminal kernel state. GitHub #107 records the defect and acceptance criteria.
