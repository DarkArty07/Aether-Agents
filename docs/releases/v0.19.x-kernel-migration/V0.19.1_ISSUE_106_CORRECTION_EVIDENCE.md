## Defect

`server.init_server()` derived Harmonia's storage authority from:

```python
config.profiles_dir.expanduser().resolve().parent
```

This allowed an external or symlinked `profiles_dir` to redirect the coordination ledger outside the configured Aether home. Gate C exposed the defect when a disposable profiles symlink resolved into the canonical runtime home.

## TDD evidence

The regression was written before production code and parameterized for both unsafe layouts:

- external profiles directory;
- symlinked profiles directory.

RED command:

```text
python -m pytest tests/coordination/test_harmonia_server.py::test_init_uses_configured_aether_home_for_harmonia_store -q
```

Observed RED:

```text
2 failed
actual:   <external-home>
expected: <isolated-control>
```

The production correction is one line:

```python
aether_home = config.aether_home.expanduser().resolve()
```

`profiles_dir` remains the ACP profile-discovery authority; it no longer controls Harmonia's project-store root.
