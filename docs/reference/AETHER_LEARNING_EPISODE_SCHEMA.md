# Protected learning episodes

Aether's source includes encrypted content storage and accepted schema concepts for protected learning evidence. This is not an active dataset export, trainer, fine-tuning service or automatic promotion path.

A valid future episode must remain project-bound, secret-redacted, attributable to trace identities and separable from compact operational indexes. Access to protected content must be explicit and auditable. Labels and comparisons must preserve unknowns, limitations, model/prompt identity and evaluator provenance.

No current tool authorizes upload, training, prompt mutation or model promotion. Those effects require a separate product decision, implementation and acceptance gate.
