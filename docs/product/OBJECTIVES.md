# Objectives

1. Produce the outcome the user requested without adjacent unrequested work.
2. Match or exceed strong single-agent quality on representative software tasks.
3. Use specialists only when their contribution improves the result more than their coordination cost.
4. Keep product authority with the user and Hermes, not with execution infrastructure.
5. Make every mutable runtime effect attributable, typed and recoverable.
6. Preserve one clear source of current truth across source, schemas, tests and docs.
7. Keep credentials and live state local and outside version control.
8. Learn through Hermes-native memory, skills and evidence without automatic self-approval.
9. Detect and expose capability gaps instead of routing through retired equivalents.
10. Close work with observable acceptance evidence and zero hidden attempt-owned survivors.
