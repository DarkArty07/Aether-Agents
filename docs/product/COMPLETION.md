# Completion contract

A task is complete when:

- the requested outcome exists in the authorized scope;
- relevant acceptance evidence passes;
- source, templates, tests and current docs agree;
- no secret or generated runtime state entered version control;
- owned temporary resources are closed or explicitly retained;
- unresolved limitations are stated as limitations, not silently converted to success.

Implementation does not imply integration; integration does not imply release; release does not imply activation or deployment.
