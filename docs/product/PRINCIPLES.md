# Principles

1. Scope fidelity precedes technical ambition.
2. One accountable owner is the default; coordination must earn its cost.
3. Tool visibility never grants authority.
4. Runtime identities are exact and are never substituted by names or paths.
5. Unknown mutation effects reconcile before retry.
6. Verification is proportional to consequence and actual failure modes.
7. Security is strict at real trust boundaries and avoids empty ceremony.
8. Runtime truth must be current, testable and documented once.
9. Historical evidence explains the past; it does not operate the present.
10. User data, secrets and live state stay local.
11. Learning requires evidence and reversible promotion.
12. Removed systems stay removed; no renamed fallback.
13. A completed local change does not imply push, release or activation.
14. Capability gaps are reported honestly rather than concealed.
