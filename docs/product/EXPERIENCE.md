# Experience

The normal experience is conversational and outcome-oriented:

1. the user states a goal;
2. Hermes resolves material ambiguity and chooses direct or admitted execution;
3. progress updates expose decisions, evidence and blockers—not raw internal noise;
4. Aether verifies the result at the appropriate depth;
5. Hermes returns the outcome, what was verified and any real remaining limit.

The user should not need to select internal tools, supervise worker mechanics or understand provider identities. Protected external effects still require explicit authority.
