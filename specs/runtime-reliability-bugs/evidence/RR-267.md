## 1. Summary of Changes

* **`src/aether_agents/lab/runner.py`**:
  * Implemented `preflight_disposable_destinations(run_root, *destinations)` to validate that disposable destinations (`kanban.db`, `worktrees`) resolve within the `run_root` sandbox, rejecting symlinks, intermediate symlink components, and escaping paths before any test writes can take place.
  * Enhanced `isolated_hermes_env(run_root, hermes_root, hermes)`:
    * Executes destination preflight on disposable roots (`kanban.db`, `worktrees`).
    * Discards inherited ambient identities: added `HERMES_DELEGATED_CHILD_CONTEXT`, `HERMES_PROJECT_ID`, `HERMES_TENANT`, and `AETHER_PROJECT_ID` to the scrub set alongside `HERMES_KANBAN_*`, `HERMES_SESSION_*`, `TERMINAL_CWD`, and `HERMES_CWD`.
    * Preserves parent environment immutability (`os.environ` is never mutated in-place).
    * Explicitly assigns disposable roots (`HERMES_HOME`, `HERMES_BIN`, `HERMES_KANBAN_DB`, `HERMES_KANBAN_WORKSPACES_ROOT`, `XDG_STATE_HOME`, `XDG_DATA_HOME`).
* **`tests/test_e2e_harness.py`**:
  * Updated `test_public_isolated_hermes_env_scrubs_all_outer_identity_from_native_kanban`:
    * Seeds a separate disposable witness Kanban database in an isolated subprocess before test execution.
    * Sets outer poisoned environment with all worker/session/project/tenant/delegated-child markers, pointing `HERMES_KANBAN_DB` to the witness DB.
    * Asserts parent environment immutability across `isolated_hermes_env`.
    * Asserts direct removal of `HERMES_PROJECT_ID`, `HERMES_TENANT`, `HERMES_DELEGATED_CHILD_CONTEXT`, and `AETHER_PROJECT_ID`.
    * Executes native subprocess under the scrubbed environment, asserting absence of leaked identities, verifying target database identity, and performing a real native `create_task`, `claim_task`, and `complete_task` sequence against the disposable laboratory board.
    * Verifies that the witness board file and its contents remain byte-for-byte identical, and parent environment remains untouched.
  * Added `test_isolated_hermes_env_rejects_symlinks_and_escaped_destinations`:
    * Validates that symlinked `kanban.db` and symlinked `worktrees` raise `HarnessError` before any writes.
    * Validates that paths escaping `run_root` raise `HarnessError`.
  * Added `test_observation_rebinds_aether_project_id_after_isolation`:
    * Verifies that `isolated_hermes_env` scrubs inherited `AETHER_PROJECT_ID`, and that observation caller rebinds a fresh project ID afterwards as designed.
