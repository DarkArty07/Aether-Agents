## 3. Investigation and Qualification Findings

Issue #294 hypothesized that background review cancellation could accidentally abort foreground turns or corrupt interrupt flags due to shared session identity. Investigation and event-controlled harness testing on the qualified baseline demonstrated:

1. **Instance and Client Isolation:** The background review fork constructs a distinct `AIAgent` instance (`review_agent is not parent_agent`). The fork builds its own HTTP client (`_client`), its own active request abort hook (`_active_request_abort`), and its own execution thread ID (`_execution_thread_id`).
2. **Cancellation Ownership:** In `conversation_loop.py` (line 1687), a new live turn proactively calls `_pending_review.interrupt("superseded by a new live turn")`. This sets `_interrupt_requested = True` on the review agent and aborts the review's in-flight socket with `interrupt_abort`. The parent foreground agent's `_interrupt_requested` remains `False`, its HTTP client is untouched, and its turn completes with its response intact.
3. **Historical Log Interpretation:** The log line `interrupt_abort` observed on `bg-review` threads during historical incidents identified an executing daemon thread aborting its own superseded review request, not an abort of the parent foreground turn. Correlation of log timestamps without thread/instance disambiguation led to the false conclusion of cross-instance interruption leakage.
4. **Controlled Interleavings Verified:**
   - *Cancel before admission:* If a review agent is interrupted before admission to its conversation loop, it exits at iteration 0 without issuing an outbound HTTP chat completion request.
   - *New foreground turn during blocked HTTP:* When review is blocked in an HTTP call and a new foreground turn arrives, the review is aborted, while the foreground agent completes cleanly with expected response and `_interrupt_requested == False`.
   - *Review completion racing next review:* `_unregister_review_agent` checks identity (`agent._background_review_agent is agent_ref` and `_active_children.remove(agent_ref)`), ensuring a predecessor review does not clear or corrupt a successor review reference (ABA-safe).
   - *Intentional /stop propagation:* When `parent.interrupt(hard_cancel=True)` is called, the parent interrupt fans out to `_active_children`, setting `_interrupt_requested = True` on the review agent.
   - *Cache and session preservation:* Review inherits `_cached_system_prompt` for exact prefix-cache parity, shares `session_id`, opts out of session DB persistence (`_persist_disabled = True`), and disables session finalization on close (`_end_session_on_close = False`).

Because all controls pass on the unchanged baseline and no interruption ownership defect exists in the qualified product code, no speculative patch was applied to `agent/background_review.py`. Per contract decision 4, Issue #294 is retained open as `not reproduced on the qualified baseline`.
