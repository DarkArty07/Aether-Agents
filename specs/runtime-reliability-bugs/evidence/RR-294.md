## 3. Investigation, Reproduction, and Qualification Findings

Issue #294 addresses background review cancellation ownership and lifecycle racing:
1. **Pre-admission Cancellation Race (Reproduced on Unchanged Baseline):**
   - On baseline `c185ee3bb5b6d609241432fd123c16143f065987`, `spawn_background_review_thread` returned `(_target, prompt)` without reserving a run token on the parent.
   - When the worker thread started, there existed a window after worker instantiation (`review_agent = AIAgent(...)`) and before registration on `parent._background_review_agent` / `parent._active_children`.
   - If user cancellation (`parent.interrupt()`) or a new live foreground turn (`conversation_loop` line 1687) arrived in this window, `_background_review_agent` was still `None` and `_active_children` did not yet contain the review worker. The cancellation was dropped, leaving the review worker uncancelled (`_interrupt_requested = False`).
   - The worker thread then proceeded to register and invoke `review_agent.run_conversation()`, sending outbound chat completion requests to the provider despite prior cancellation.
   - **Baseline Test Result (RED):** 2 failed (`test_pre_admission_cancellation_prevents_request`, `test_pre_admission_superseding_turn_prevents_request`), 6 passed.
2. **Causal Repair via Upstream Run Token Handshake:**
   - Adapted `_BackgroundReviewRun`, `prepare_background_review_run`, `finish_background_review_run`, and `_track_review_fork` from upstream `NousResearch/hermes-agent@9fd44b4dfc44138b9e5d5689acb56c438364ff7b` (lines 914-1136).
   - In `spawn_background_review_thread`, `prepare_background_review_run(agent)` installs `_BackgroundReviewRun` on `agent._background_review_run`, `agent._background_review_agent`, and `agent._active_children` *before* `Thread.start()`.
   - If parent interrupt or new turn arrives before admission, `run.interrupt()` calls `run.cancel()`, which latches `cancel_requested.set()`.
   - When the worker reaches admission, `review_run.begin_request(review_agent)` checks `cancel_requested.is_set()` and atomically returns `False`. Admission is denied, preventing `run_conversation()` from executing and eliminating all outbound HTTP requests.
   - When admitted normally (no cancellation), `begin_request` registers `review_agent` into tracking slots. If cancelled in-flight, the interrupt propagates to the admitted review agent.
   - Cleanup via `_track_review_fork` and `finish_background_review_run` is identity-qualified (ABA-safe against successor reviews).
   - **Candidate Test Result (GREEN):** All 8 tests in `tests/run_agent/test_background_review_interruption_ownership.py` passed (0 failed). All 38 tests across all 5 review test files passed cleanly.
