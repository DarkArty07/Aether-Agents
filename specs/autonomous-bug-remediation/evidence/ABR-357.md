## 2. Root-cause investigation and judgement

The qualification test at
`tests/test_observation_qualification.py:73-285` constructs a real Hermes
`PluginManager` and `PluginContext`, registers the Aether observer, invokes tool and
API hooks, checks the measured 22-hook registration, calls `manager.unload(manifest)`,
and then checks that every hook is gone. It also validates persisted events and
asserts that raw prompt, response, command, result, and subagent payload markers are
absent.

The observer teardown at
`src/aether_agents/observation/capture/hermes_plugin.py:3041-3046` stops only its
reconciliation worker and collector. The exact Hermes source registers hook callbacks
through the manager ownership ledger at `hermes_cli/plugins.py:3109-3132` and
performs reverse-order registration disposal followed by manager hook cleanup at
`hermes_cli/plugins.py:3610-3736`. The source path therefore contains no demonstrated
unload omission, and the real execution below confirms the expected result.

A direct test invocation without the exact Hermes wrapper produced:

```text
s
1 skipped in 0.14s
```

The test's `pytest.importorskip("hermes_cli.plugins")` is the reason: the ordinary
manager environment did not provide `hermes_cli`. This is an environment-only
prerequisite result, not a product failure and not a harness assertion failure.

With the exact locked source selected by the Aether wrapper, the same test passed.
One hundred fresh wrapper subprocess invocations also passed without a failure. No
sleep, deadline increase, retry-based acceptance, or timing assertion was added. Since
there was no intermittent failure to drive a race investigation, no new event/barrier
harness was warranted; the existing test's hook calls and synchronous unload assertion
were left unchanged.

**Judgement:** no product unload/hook leak and no qualification-harness race were
demonstrated. The historical failure is not reproducible from the available evidence;
the only observed failure-like state is the unqualified environment that lacks the
Hermes runtime. A later recurrence must preserve its first failing environment/source
identity rather than treating a retry pass as a fix.
