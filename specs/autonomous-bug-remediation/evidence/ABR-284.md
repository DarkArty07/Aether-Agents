## 1. Scope and Outcome

Project initialization (`aether init`) ensures the native project-linked worktree root (`/.worktrees/`) is excluded from Git tracking without requiring each product objective to commit a Hermes-specific ignore rule. The operation is idempotent, preserves existing unrelated `.gitignore` content, and refuses rather than hiding an already tracked conflicting `.worktrees` path. Worktree creation, execution, and removal remain functional.
