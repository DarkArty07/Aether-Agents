## 2. Source findings and technical judgement

The permitted fork already contains the native vision implementation from the upstream
vision work (`3800972dd05eabed8d75bfc4c0f5d532d85dafe2`, inspected in the fork history):

- `tools/vision_tools.py:967-1036` declares `openai-codex` compatible with multimodal
  tool results, and `:1039-1066` gates the native fast path on the active model's image
  capability.
- `tools/vision_tools.py:1142-1288` resolves a local source through the image resolver,
  reads and normalizes the bytes, and returns a native multimodal envelope.
- `tools/vision_tools.py:1756-1794` dispatches `vision_analyze` to that native path.
- `agent/codex_responses_adapter.py:154-202` converts Chat-style `image_url` parts to
  Responses `input_image` parts.
- `agent/codex_responses_adapter.py:693-724` emits a tool result as
  `function_call_output.output` with an array of `input_text`/`input_image` parts, and
  `:795-844` validates and preserves that array.

This is the documented Responses shape: the OpenAI function-calling guide states that
function outputs may be an array of image/file objects, and the OpenRouter Responses
reference documents `function_call_output.output` arrays containing `input_text` and
`input_image`. The maintained fork's conversion is therefore not shown to be malformed
by the available evidence.

The current upstream counterpart remains open:

- [NousResearch/hermes-agent#82250](https://github.com/NousResearch/hermes-agent/issues/82250)
  reports text-only Codex success but all native image inputs failing with `server_error`
  on the ChatGPT/Codex Responses endpoint.
- [#82284](https://github.com/NousResearch/hermes-agent/issues/82284) is marked a duplicate
  of #82250 and reports the same valid-PNG/native-routing symptom.

The issue reports are consistent with the local request-shape result below. No current
upstream patch or released request-shape correction for this backend behavior was found.
A new provider-specific wire format would be a guess and could violate the provider/auth
boundary, so this unit takes the contract's permitted external-defect disposition.
