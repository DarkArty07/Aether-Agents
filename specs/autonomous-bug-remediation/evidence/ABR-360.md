## 3. Findings and Technical Judgement

1. **Root Cause Analysis (Baseline RED):**
   - In `scripts/qualify_observation.py`, command execution via `_run` previously routed all failed command `completed.stderr` through `_content_free_stream_tail`.
   - `_content_free_stream_tail` intentionally replaces arbitrary stream lines with character counts and SHA-256 hashes (`line(chars=...,sha256=...)`).
   - When Git commands failed during qualification—such as `git checkout --detach e624e9fde561e1add9388384012b295fde669ade` failing with exit code 128 during observation qualification on Python 3.12—the exception surfaced solely as:
     `RuntimeError: command failed (git exit 128): stdout_tail=[empty]; stderr_tail=[line(chars=72,sha256=434892a8c3f7c0d3)]`
   - This completely suppressed the actual Git diagnostic (e.g. network disconnect, promisor pack failure, unresolved host, unreadable blob, or ref lock contention), making transient failures impossible to diagnose from CI job logs.
   - Retrying is not a fix; operators and developers need bounded Git diagnostics to identify the real underlying failure mode without leaking credentials.

2. **Causal Remediation (Candidate GREEN):**
   - Added `_git_diagnostic_tail(stream)` in `scripts/qualify_observation.py`, invoked when `_is_git_command(arguments)` is true.
   - Filters lines against `_GIT_DIAGNOSTIC_LINE_RE` matching standard Git severity prefixes (`fatal:`, `error:`, `warning:`, `remote:`, `hint:`).
   - Sanitizes sensitive data:
     - URL credentials (`https://<redacted>@...`)
     - Authentication values (`authorization=...`, `token: ...`, `password=...`, `secret=...`)
     - Bearer tokens (`bearer <redacted>`)
     - Well-known token prefixes (`ghp_`, `github_pat_`, `glpat-`, `xox-`, `sk-`)
     - Private filesystem paths (`/home/...`, `/Users/...`, `C:\Users\...`, `/tmp/...`, `/var/tmp/...`) mapped to `<path>`
     - Control characters stripped and whitespace normalized
   - Bounded by strict limits: maximum 8 diagnostic lines, 512 characters per line, and 2048 characters total budget.
   - Falls back safely to `_content_free_stream_tail` when no recognized Git severity line is found or when the command is not Git.
   - Added unit tests in `tests/test_hermes_baseline.py` exercising sanitized diagnostic extraction, redactions, fallbacks, and integration with `checkout_exact`.
