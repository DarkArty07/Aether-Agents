# Tools, memory and runtime stability — five-issue remediation

## Intent, authority and ownership

The owner requests autonomous, pragmatic resolution of Aether-Agents #275, #373,
#382, #389 and #390 through Supervisor and Implementer, including finding the cause,
verified fixes, integration and authorized routine closeout. This is not an
investigation-only objective. Morfeo owns this specification and material design;
Supervisor owns receipt review, tasks.md, decomposition, review convergence and
terminal integration. Implementer owns bounded implementation. No units are defined
by this document.

The accepted R0 constitution and PD-71..PD-74 remain unchanged. Current explicit
remediation authority permits indispensable downstream bug fixes, not features or
unrelated framework upgrades. The owner-approved maintained Hermes fork is the
repair source; stale transitional-fork wording does not authorize copying dirty
runtime state or advancing the selected public release lock.

The five existing GitHub issues are the canonical defect records; this contract is
the batch objective. Intake reuses them rather than creating a duplicate bug or a
ceremonial umbrella Issue. AGENTS.md exists and is preserved. Update affected guidance
only when an authorized behavior change makes it inaccurate; otherwise record why
no change is applicable.

## Explicit research gates for TS-275 and TS-382

These two remediation surfaces are not yet build-qualified. Their first executable
outcome is bounded causal qualification, not speculative implementation. Each must
produce: (1) exact loaded source/route; (2) discriminating failing scenario and
sanitized observation; (3) causal boundary; (4) smallest compatible repair proposal;
(5) runnable pre/post acceptance oracle. The complete issue remains required after
this research outcome. A research result or genuine capability blocker is not issue
closure or owner-objective acceptance.

Supervisor may execute these bounded research outcomes alongside the already
build-qualified requirements. Before implementing either newly discovered repair,
return its material premise to Morfeo through the native contract revision/continuation
path; Morfeo records the evidence-backed design in plan.md and supersedes contract
bytes if required. This is an autonomous design checkpoint, not a routine owner
approval question. Healthy independent work must continue. Supervisor/Implementer
must not invent an unresolved transport, persistence or external-product design.

## Authority boundary

Authorized: provisioned Aether role execution; source inspection; isolated fixtures;
local commits; existing-credential issue comments, ordinary branch push/PR/checks/merge
and objective-owned merged residue cleanup in Aether-Agents and aether-hermes;
small indispensable fixes in those repositories; normal locked development dependency
setup in isolated environments; bounded real vision qualification through the
already provisioned route. No new model/provider subscription or credential acquisition.

Scoped runtime adoption is authorized only for independently reviewed relevant fixes,
using the existing maintained-runtime mechanism, preserving unrelated dirty changes
and active work. Drain/reload at a safe boundary and retain exact rollback evidence;
never replace the entire dirty editable tree or interrupt healthy workers. If the
existing safe mechanism cannot adopt the candidate, report the specific blocker.

Not authorized: widening credentials/access/spend, broad backend/router-product edits,
repository settings, force/history rewrites, check bypass, package publication,
deployment, release-lock migration, destructive live DB maintenance or feature work.
A route that needs an external backend change is an evidence-backed boundary to return,
not permission to alter that separate product. Routine merge must not silently trigger
an otherwise unauthorized deployment.

## Decisions and limits

Testing is explicitly resolved from CONTRIBUTING.md and current locked repository
checks, supplemented by the causal and native oracles above; quickstart.md is the
runnable path. No universal throughput target or new coverage floor is invented.
Private implementation-equivalent choices are delegated; shared/public shapes,
isolation, persistence semantics and acceptance are not.

Review convergence follows the current canonical supervisor-decomposition procedure:
consolidate known failures, suspend a non-convergent patch strategy, and return a
material design defect to Morfeo without cancelling healthy independent work.
Duration alone is not a failure criterion. A protected-edge denial is authoritative.

Compatibility target: bug-fix behavior, expected release_impact=patch, to be verified
from actual diffs. release_action=defer; release_channel=none. Merge is not release.

Morfeo performs contract-result-review against the exact integrated revision before
owner acceptance. Supervisor owns normal execution closeout.
