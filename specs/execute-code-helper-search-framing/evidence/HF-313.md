## HLP-313 — execute_code helper explicit import contract

- **Reason:** `execute_code` schema and CLI tips advertised `json_parse`, `shell_quote`, and `retry` as no-import built-in globals, and `_sandbox_failure_hint` instructed users to call them directly or remove imports when failures occurred. In reality, helpers are defined as exports in generated `hermes_tools.py` and require explicit imports (`from hermes_tools import ...`). Calling them directly resulted in NameError, and following the failure hint created unrecoverable loops.
- **Primary active files:**
  - `tools/code_execution_tool.py`
  - `hermes_cli/tips.py`
  - `tests/hermes_cli/test_tips.py`
  - `tests/tools/test_sandbox_failure_hints.py`
  - `tests/tools/test_execute_helper_contract.py`

- **Upstream:** Adapted from merged upstream commit `65f033a1a20e847b7a150fe6168cd345385c7d07` (PR `NousResearch/hermes-agent#83772`, credit @yuzilongleif-collab).
