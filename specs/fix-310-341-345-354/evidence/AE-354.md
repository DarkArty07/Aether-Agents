## 3. Investigation and Defect Mechanism

### 3.1 Defect Mechanism (Reproduced on Unchanged Baseline `6562c09`)
On unchanged `6562c09`:
1. `hermes_plugin._handle()` instantiated `ObjectiveContractStore(author_profile=author_profile)` without deriving or passing an authoring root.
2. `store._project(project_id)` always resolved to `self.registry.project_path(canonical)`, which points to the primary checkout.
3. As a result, when an operator authored a contract while operating in an exclusive linked worktree:
   - Draft files (`.aether/drafts/`) and finalized contracts (`.aether/objective-contracts/`) were written directly into the primary checkout, mutating its worktree and creating dirty status on the primary branch.
   - `prepare_handoff` executed `git rev-parse HEAD` and `git show` against the primary checkout. If the primary checkout was on another branch or lacked the worktree's contract commit, `prepare_handoff` returned `{"handoff_ready": False, "reason": "NOT_IN_BASE"}`.
   - Execution board metadata created by `_create_metadata_exclusive` did not contain or validate `worktree_base_ref`, so downstream worktrees would spawn from whatever commit was currently checked out at the primary `default_workdir`.

### 3.2 Fail-First Reproduction (RED on `6562c09`)
When executing `test_session_worktree_authoring_preserves_primary_and_provisions_worktree_base_ref` against the baseline:
```text
FAILED tests/test_objective_contracts.py::test_session_worktree_authoring_preserves_primary_and_provisions_worktree_base_ref
assert not (primary / ".aether" / "drafts").exists()
AssertionError: assert not True
where True = ((PosixPath('.../alpha') / '.aether') / 'drafts').exists()
```
The test confirmed that authoring written from a worktree session wrote through to the primary checkout, dirtying its status and failing isolation.

### 3.3 Implementation Details (GREEN on Candidate)
1. **Native Session Workspace Resolution:** In `src/aether_agents/objective_contracts/hermes_plugin.py`, added `_native_session_workspace(session_id: str) -> Path | None` which directly inspects `$HERMES_HOME/state.db` read-only (`mode=ro`, `PRAGMA query_only=ON`) to read the exact session's `cwd` and resolves it to its Git top-level via `git rev-parse --show-toplevel`. This reuses the session workspace reading technique without importing any knowledge modules into the contract plugin.
2. **Authoring Root Binding and Validation:**
   - In `ObjectiveContractStore.__init__`, added optional `authoring_root: Path | None = None`.
   - In `_project(project_id)`, after validating the registered primary root in `ProjectRegistry`, if `authoring_root` is set and distinct from `primary_root`:
     - Verifies `authoring_root` is a directory, not a symlink.
     - Verifies `authoring_root / ".aether" / "project.toml"` conforms to the canonical marker schema and has `project_id == canonical`.
     - Verifies `git rev-parse --show-toplevel` matches `authoring_root`.
     - Verifies `git rev-parse --git-common-dir` in both `authoring_root` and `primary_root` resolve to the exact same `.git` common directory.
     - Fails closed with `AETHER-OBJECTIVE-CONTRACT-PROJECT-CONFLICT`, `AETHER-OBJECTIVE-CONTRACT-PROJECT-MARKER-INVALID`, or `AETHER-OBJECTIVE-CONTRACT-PROJECT-GIT-ROOT` on any mismatch.
   - Storing drafts, final contracts, and checking Git commits occurs in `authoring_root`, leaving `primary_root` completely clean and byte/status unchanged.
3. **Primary Root Preservation for Execution Board:**
   - In `store.prepare_handoff()`, `on_ready` is invoked with `primary_root` (`self.registry.project_path(project_id)`), ensuring the native Hermes Project and board `default_workdir` remain anchored to the registered primary path.
4. **Shared Interface `worktree_base_ref`:**
   - Added `_BASE_REF_RE = re.compile(r"^[0-9a-f]{40}$")`.
   - `_create_metadata_exclusive` writes `worktree_base_ref` (40-char lowercase SHA-1) into board metadata.
   - `_validate_execution_metadata` validates that `metadata["worktree_base_ref"]` is valid and matches the current prepared contract `base_commit`.
   - `prepare_handoff` passes `worktree_base_ref=str(prepared["base_commit"])` to board provisioning.
