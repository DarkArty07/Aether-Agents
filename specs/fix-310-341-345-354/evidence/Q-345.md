## 2. Root Cause Analysis & Classification

### Investigation: Stale Fixtures vs. Product Regression
1. **D345 Cache Semantics**:
   - D345 specifies that semantic chunk cache lookup and cache publication require a concrete resolved route (`is_route_resolved(expected_route)`).
   - If the route is unresolved (e.g. `provider="auto"` or `provider="unresolved"`), cache publication and cache lookup are intentionally skipped to prevent cache poisoning across arbitrary or indeterminate models/providers.
2. **Exact Public Hermes Baseline (`v2026.8.18`)**:
   - Under exact public Hermes checkout without ambient user profile files (matching CI environment with sterile `HOME`/`HERMES_HOME`), calling `_resolve_task_provider_model("web_extract")` yields `('auto', None, None, None, None)`.
   - When test configurations only specified `{"semantic_auxiliary_task": "web_extract"}` without route metadata, `resolve_auxiliary_route` produced `{"provider": "auto", "model": "default", "api_mode": "default"}`.
   - Under this unresolved route, `is_route_resolved` correctly evaluated to `False`.
3. **Observed Failures in CI run `34301307930`**:
   - `test_d35_cross_project_isolation_and_symbol_collision`: because `is_route_resolved` was `False`, `run_semantic_extraction` skipped cache publication. `cache_a_files` was empty (`len(cache_a_files) == 0`), failing `assert len(cache_a_files) > 0`.
   - `test_gx06_deadline_seconds_zero_pending_honest_coverage`: cache entry was seeded without route metadata, but `run_semantic_extraction` skipped cache lookup because `expected_route` was unresolved (`auto`). Thus chunk 0 was not restored from cache, and when deadline expired, all chunks were deferred as pending (`state == "pending"` instead of `"partial"`).
   - `test_gx06_resume_uses_validated_cache_and_progresses_pending`: Run 1 skipped cache publication due to unresolved route. Run 2 skipped cache lookup. Chunk 0 was not cached, resulting in `state == "pending"` instead of `"partial"`.
4. **Conclusion**:
   - Production logic in `src/aether_agents/knowledge/semantic.py` is fully sound: resolved routes cache and publish correctly, and unresolved/mismatched routes skip cache publication and reuse.
   - The failures were stale test fixtures that lacked an explicit resolved non-secret route configuration.
   - Giving D35 and GX-06 explicit resolved non-secret routes (`provider="openrouter"`, `model="meta-llama/llama-3-70b-instruct"`, `api_mode="chat_completions"`) resolves `expected_route` deterministically under exact Hermes without constructing live clients or using credentials, allowing the full caching and cross-project isolation behavior to be proven.
