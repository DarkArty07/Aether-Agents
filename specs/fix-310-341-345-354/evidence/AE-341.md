## 3. Candidate Implementation

Changes applied to `src/aether_agents/knowledge/memory.py`:
1. **Tracked and untracked dirty source checking:**
   Implemented `_is_dirty(ctx: KnowledgeContext) -> bool` combining tracked changes (`git diff --name-only -z <revision>`) and untracked changes (`git ls-files --others --exclude-standard -z`), mirroring `snapshots.py` `_dirty` semantics. Freshness in both `search` and `read` evaluates to `"revalidate"` when either tracked or untracked changes exist.
2. **Immutable metadata validation:**
   Implemented `_validate_record_metadata(record: dict[str, Any]) -> None` in `memory.py` validating that required immutable fields (`source_revision`, `markdown_sha256`, `actor`, `situation`, `lesson`, `applicability`, `outcome`, `source_nodes`, `evidence`, `verification`, `updated_at`) are present with correct schemas and formats.
3. **Record loading and index error translation:**
   Updated `_record` to catch `INDEX_CORRUPT` from `load_json` and map it to `MEMORY_CORRUPT`, then run `_validate_record_metadata`.
4. **Note content and SHA-256 hash verification:**
   Implemented `_verify_note_content(path: Path, record: dict[str, Any]) -> bytes`, ensuring `note.md` is present, readable, and that `hashlib.sha256(raw).hexdigest() == record["markdown_sha256"]`. If missing or mismatched, raises `KnowledgeError("MEMORY_CORRUPT")`.
5. **Reflection note validation before cache reuse:**
   In `_reflect`, all current notes in `index["heads"]` and their markdown hashes are read and verified via `_record` and `_verify_note_content` *before* checking `reflection.json`. If any note is missing or corrupt, `MEMORY_CORRUPT` is raised immediately. If all notes pass validation, existing valid cache reuse (`reused: True`) is preserved. When backend is None on a corrupt note, `MEMORY_CORRUPT` is raised, never `COMPONENT_UNAVAILABLE`.
6. **Search and read note verification:**
   Both `search` and `read` verify note content integrity and hashes using `_verify_note_content`.
