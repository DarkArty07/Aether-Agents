## Review-round-1 corrections (review run 19, changes requested)

### 1. Raw streams never establish a failure class

- The stream-scraping `_exception_class_from_streams` helper is removed. A markerless or
  unqualified failure now retains the fixed, content-free
  `QUALIFICATION_FALLBACK_FAILURE_CLASS = "SubprocessFailure"` (`scripts/qualify_observation.py:136`)
  with `failure_kind=exception`; no assertion kind, class or payload text is ever recovered from
  raw stdout/stderr. A class-shaped allowlist is not provenance: an assertion value such as
  `PrivatePayloadError`, or an ordinary stderr token such as `PrivateTokenFailure`, would
  otherwise be retained verbatim.

### 2. Marker provenance, phase scope and exact source/runtime identity

- `_qualification_failure_diagnostic` (`scripts/qualify_observation.py:312`) consults a marker
  only when the runner phase is exactly `qualification_harness` (line 336). Every other phase
  ignores markers entirely.
- `_diagnostic_from_marker` (`scripts/qualify_observation.py:246`) accepts a marker only when
  (a) `schema_version` matches, (b) it carries the per-invocation nonce
  (`AETHER_QUALIFICATION_DIAGNOSTIC_NONCE`, 32 lowercase hex) that `_qualification_environment`
  (`scripts/qualify_observation.py:644`) provisions with `secrets.token_hex(16)` and overwrites
  any ambient value, and (c) its `source_commit` equals the runner-verified
  `AETHER_QUALIFICATION_SOURCE_COMMIT` exactly. Failing any check, the marker is treated as
  untrusted output.
- Runtime is retained only from a provenance-qualified marker (lines 298–301); the fallback and
  `_harness_result_failure` (`scripts/qualify_observation.py:511`) omit runtime rather than
  substituting the runner's own interpreter identity.
- Harness emitter: `_emit_qualification_failure`
  (`tests/test_observation_qualification.py:57`) echoes the exact nonce it received (line 79);
  without it the runner cannot accept the line as harness state.
