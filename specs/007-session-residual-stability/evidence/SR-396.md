# SR-396 implementation evidence

## Scope

Unit U396 binds contract observation to the verified execution board and project instead of ambient authoring/current/default state. The change is limited to observation capture, the minimal `prepare_handoff` board metadata binding, focused observation tests, and this evidence record.

## Changes

- `src/aether_agents/objective_contracts/hermes_plugin.py`: carries the verified `observation_trace_id` into execution-board metadata and validates it on reuse.
- `src/aether_agents/observation/capture/hermes_plugin.py`: keeps a trace-to-project/contract/version/board binding, reconstructs bindings only from canonical `board.json` metadata and the exact contract marker, selects collectors per verified project, passes the explicit board slug to `kanban_db_path(board_slug)`, validates the board tuple and canonical DB path, refuses default-board fallback, follows parent links, and normalizes native review terminal event status to `completed` while retaining `run_outcome`.
- `src/aether_agents/observation/contracts.py`: maps native `review_requested` and `changes_requested` event statuses to `completed`.
- `tests/test_observation_cli_plugin.py`: disposable board fixtures now create canonical board metadata and use the explicit board path.

No change was made to journal ingestion or the reducer.
